# Autonomous Search & Rescue Drone

A Python-based autonomous drone system for search and rescue operations using object detection and PS5 controller integration.

## Features
- Real-time object detection with YOLO
- PS5 controller manual flight control  
- Search pattern automation
- Tello drone integration

## Tech Stack
- Python, OpenCV, YOLO, PyGame
- DJI Tello drone
- PS5 controller input
