## 🚀 PyCharm Setup Guide for Students

Follow these steps to open, configure, and run the Search & Rescue Drone project in PyCharm.

### 1. Open the Project in PyCharm
1. Download this repository as a ZIP file and extract it, or clone it using Git.
2. Open **PyCharm**.
3. Click **Open** and select the extracted `PythonDrone` folder.

### 2. Configure the Virtual Environment & Dependencies
PyCharm makes installing dependencies easy:
1. When you open the project, PyCharm will notice the `requirements.txt` file and display a yellow notification bar at the top of your editor saying: 
   *"Package requirements... are not satisfied"*.
2. Click **Install requirements** in that yellow bar. 
3. Alternatively, if you don't see the bar:
   - Go to **Settings** (or **Preferences** on Mac) > **Project: PythonDrone** > **Python Interpreter**.
   - Click the **+** icon, search for the missing packages (`djitellopy`, `opencv-python`, `ultralytics`, `pygame`, `numpy`), and click **Install Package**.

### 3. Connect to the Tello Drone
1. Turn on your DJI Tello drone.
2. Open your computer's Wi-Fi settings and connect to the drone's network (e.g., `TELLO-XXXXXX`).

### 4. Running the Code in PyCharm
You don't need to use the terminal. You can run the scripts directly inside the IDE:
1. Right-click on the script you want to run in the project tool window on the left side:
   - **For Autonomous Tracking:** Right-click `Autonomous_human_lock_flight.py` and select **Run**.
   - **For Manual Controller Flight:** Connect your PS5 controller to your computer via USB or Bluetooth. Then right-click `Finall_Ps5_controller.py` and select **Run**.
2. To stop the drone safely at any time, click the red **Stop button** (square icon) in the PyCharm run tool window.
